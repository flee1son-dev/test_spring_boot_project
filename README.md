# test_spring_boot_project REST API

## О проекте
Данный проект представляет собой backend-приложение для управления задачами, разработанное на **Spring Boot**. API позволяет создавать, редактировать, удалять и просматривать задачи, а также управлять их жизненным циклом (запуск, завершение, возобновление).

Проект демонстрирует использование современных практик разработки на Java: разделение на слои, валидацию данных, централизованную обработку ошибок и работу с базой данных через Spring Data JPA.

## Технологический стек
*   **Java 25**
*   **Spring Boot 4.1.2**
*   **Spring Web MVC** — для создания RESTful-эндпоинтов
*   **Spring Data JPA** — для работы с базой данных
*   **PostgreSQL** — в качестве СУБД
*   **Jakarta Validation** — для валидации входящих DTO
*   **SLF4J** — для логирования
*   **Maven** — для сборки проекта
*   **JUnit 5** — для тестирования

## Функциональность
*   **CRUD операций:** Создание, чтение (по ID и списком), обновление и удаление задач.
*   **Фильтрация и пагинация:** Получение списка задач с фильтрацией по `creatorId` и `assignedId`, а также с поддержкой постраничного вывода (`pageSize`, `pageNumber`).
*   **Управление статусом задачи:**
    *   `POST /tasks/{id}/start` — Запуск задачи с назначением исполнителя.
    *   `POST /tasks/{id}/complete` — Завершение задачи (установка статуса и даты выполнения).
    *   `PUT /tasks/{id}/resumption` — Возобновление задачи.
*   **Валидация данных:** Проверка обязательных полей и корректности дат (`@Future`, `@FutureOrPresent`) перед сохранением.
*   **Обработка ошибок:** Глобальный обработчик исключений возвращает клиенту понятные JSON-ответы с кодом ошибки и временной меткой.

## Запуск проекта

### Предварительные требования
*   Установленный **JDK** (версия 17 или выше).
*   Установленный **Maven**.
*   Запущенный экземпляр **PostgreSQL**.

### Настройка базы данных
1.  Создайте базу данных `homework_spring_db`.
2.  В файле `src/main/resources/application.properties` укажите ваши учетные данные:
    ```properties
    spring.datasource.url=jdbc:postgresql://localhost:5432/homework_spring_db
    spring.datasource.username=ВАШ_ЛОГИН
    spring.datasource.password=ВАШ_ПАРОЛЬ
